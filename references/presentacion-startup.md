# Presentación de tu startup

Tienes 1 minuto y una sola slide. El objetivo es que otra startup sepa en qué se puede integrar contigo.

1. **Quiénes somos:** nombre y qué problema resolvemos, en una frase.
2. **Para quién:** clínicas, profesionales o pacientes, y cuántos usuarios tienes hoy.
3. **Qué exponemos:** API REST, webhooks, FHIR/HL7, servidor MCP, SDK o exportación de archivos.
4. **Qué datos entran y salen:** por ejemplo, entra una hora agendada y sale un informe clínico.
5. **Con quién queremos integrarnos:** el tipo de solución (ficha, agenda, laboratorio, pagos, telemedicina).
