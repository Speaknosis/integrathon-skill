# Qué tener preparado

Las parejas de integración se arman antes del evento. La organización envía los contactos al cierre de inscripciones, el viernes 13 de noviembre. En cuanto te llegue tu pareja, comparte con la otra startup lo siguiente, antes del día del evento:

- [ ] NDA bilateral firmado con tu pareja (`templates/nda-bilateral.md`).
- [ ] Documentación de tu API o punto de integración, con ejemplos de request y response (`references/documentacion-integracion.md`).
- [ ] Ambiente sandbox con credenciales de prueba para la otra startup (`references/ambiente-sandbox.md`).
- [ ] Datos de prueba sintéticos: pacientes, horas y fichas inventados. Nada de datos reales, ni siquiera anonimizados.
- [ ] El flujo que van a construir, acordado en una frase. Ej: "la hora agendada crea la consulta en la ficha".
- [ ] Un llamado de 30 minutos con tu pareja para resolver dudas antes del día.
- [ ] Al menos una persona técnica que pueda escribir código durante todo el evento, con su notebook.
